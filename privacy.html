Privacy Policy

Last updated: 10 October 2026

This Privacy Policy explains how KW Lab ("the application") accesses, uses, stores and protects Google user data. The application is a private tool used only by its owner.

1. Data accessed

With the user's explicit consent through Google sign-in, the application requests the following Google API scopes:

Google APIScopePurpose
Google Ads APIadwordsRead campaign, keyword and search term reports; estimate search volumes with Keyword Planner; prepare changes that a human validates before they are applied.
Google Analyticsanalytics.readonly, analytics.editRead website traffic and conversion reports; configure conversion events when asked.
Google Tag Managertagmanager.readonlyCheck that conversion tags are installed correctly.
Google Search Consolewebmasters.readonlyRead organic search performance.
Google Merchant CentercontentRead product feed health when relevant.

2. How the data is used

Google user data is used only to provide the features described above to the application's owner: auditing accounts, planning campaigns and checking tracking. It is not used for advertising, profiling or any other purpose.

3. Storage and security

The application runs locally on its owner's computer. OAuth tokens are stored only on that computer and are never sent to any server operated by the application. Reports retrieved from Google APIs are processed locally and are not stored in any external database.

4. Sharing

Google user data is never sold, rented or shared with third parties, and is not transferred to data brokers or information resellers. It is not used to train artificial intelligence models.

5. Limited Use

KW Lab's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. Retention and deletion

Access can be revoked at any time from the Google Account permissions page (myaccount.google.com/permissions). Deleting the local token file removes all stored credentials immediately.

7. Contact

For any question about this policy: contact@kwlab.eu.
